# Deployment Guide

## Build Artifacts
- Unpacked: `dist/`
- Zip package: generated by `npm run package` as `edplan-sync-extension-v<version>.zip`

## Manual Deployment
1. Run `npm run build`.
2. Load `dist` as unpacked in `chrome://extensions`.

## Enterprise Deployment (Chrome Admin)
1. Run `npm run package`.
2. Upload zip/package to internal extension distribution process.
3. Assign deployment by Organizational Unit (OU) in staged rollout:
   - Pilot OU
   - Limited production OU
   - Full production OU
4. Monitor error rates before broadening rollout.

## Rollback
- Re-publish prior stable package version.
- Trigger rollback if elevated:
  - session validation failures
  - submit verification failures
  - unknown terminal error rate
